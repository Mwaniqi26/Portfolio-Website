# Alex Mwangi Portfolio Website 🌐

This is a responsive, animated personal portfolio website for **Alex Mwangi**, built with **HTML, CSS, Bootstrap**, and enhanced with features like dark mode, skill animations, Swiper sliders and a working contact form using **Formspree**.

## 🔗 Live Demo

[View Portfolio Live](https://mwaniqi26.github.io/Portfolio-Website/)  

---

## 🚀 Features

- 💻 Responsive Design (Bootstrap 5)
- 🎨 Custom Skills Progress Bars
- 🎥 AOS Animations on Scroll
- 🌙 Dark/Light Mode Toggle
- 🔁 SwiperJS Carousels for Projects & Services
- 💬 AJAX Contact Form via Formspree
- 🔗 Social Media Links
- 📤 Back-to-top Button
